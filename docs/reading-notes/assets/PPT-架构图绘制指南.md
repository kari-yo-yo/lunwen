# 🎨 论文架构图 PPT 绘制指南 —— "莱昂的科研日记" 风格

> 本指南详细说明如何在 PowerPoint 中绘制与项目网站一致的论文架构图，包含完整的颜色编码、形状规范和排版规则。

---

## 一、核心色彩体系（莫兰迪低饱和色系）

### 1.1 主色调（按模块功能分配）

| 模块类型 | 颜色名称 | HEX | RGB | 适用场景 |
|----------|----------|-----|-----|----------|
| **输入/输出层** | 暖桃色 | `#F2CEB0` | `RGB(242, 206, 176)` | 输入图像、输出结果、数据流起点终点 |
| **特征提取/编码器** | 鼠尾草绿 | `#B0D194` | `RGB(176, 209, 148)` | 卷积层、编码器、特征提取模块 |
| **注意力/核心创新** | 玫瑰粉 | `#EA9D9D` | `RGB(234, 157, 157)` | 注意力模块、核心创新点、关键操作 |
| **融合/解码器** | 深藏青 | `#385492` | `RGB(56, 84, 146)` | 特征融合、解码器、上采样、拼接 |
| **损失/辅助分支** | 暗砖红 | `#A72A35` | `RGB(167, 42, 53)` | 损失函数、辅助监督、残差连接、Skip Connection |
| **背景/说明框** | 浅灰蓝 | `#E8E4E1` | `RGB(232, 228, 225)` | 说明文字框、注释框、图例背景 |
| **中性/通用模块** | 米白色 | `#F5F0EB` | `RGB(245, 240, 235)` | 通用处理模块、中间层、未特别标注的模块 |
| **频率/频域模块** | 淡紫灰 | `#C5B9CD` | `RGB(197, 185, 205)` | FFT、DCT、小波变换、频域处理 |
| **空间/像素模块** | 薄荷灰绿 | `#A8C5B5` | `RGB(168, 197, 181)` | 空间注意力、像素级操作、池化 |

### 1.2 辅助色（线条、文字、装饰）

| 元素 | 颜色名称 | HEX | RGB | 用途 |
|------|----------|-----|-----|------|
| **主标题文字** | 深炭灰 | `#2D3436` | `RGB(45, 52, 54)` | 图标题、大标题 |
| **模块内文字** | 中灰 | `#4A4A4A` | `RGB(74, 74, 74)` | 模块内部标签、公式符号 |
| **数据流箭头** | 中灰蓝 | `#6C7A89` | `RGB(108, 122, 137)` | 主数据流箭头 |
| **跳跃连接/残差** | 虚线灰 | `#95A5A6` | `RGB(149, 165, 166)` | Skip Connection、残差分支（虚线） |
| **强调高亮** | 暗金 | `#B8956A` | `RGB(184, 149, 106)` | 需要特别强调的模块边框或文字 |
| **外框描边** | 浅灰 | `#BDC3C7` | `RGB(189, 195, 199)` | 模块矩形外框（1pt） |

### 1.3 色彩使用原则

```
同一架构图中，主色调不超过 5 种（输入桃色 + 特征绿色 + 注意力粉色 + 融合蓝色 + 损失红色）
辅助色统一使用深灰系，避免喧宾夺主
相邻模块尽量使用不同主色，增强可区分性
同类型模块使用同色系（如所有注意力子模块都用粉色系的不同深浅）
```

## 二、PPT 形状规范

### 2.1 模块矩形

| 属性 | 规范 |
|------|------|
| **形状** | 圆角矩形（Rounded Rectangle） |
| **圆角半径** | 0.15 cm ~ 0.2 cm（根据模块大小调整） |
| **填充** | 纯色填充，透明度 0%（不透明） |
| **边框** | 实线，1 pt，颜色 `#BDC3C7`（浅灰） |
| **阴影** | 无阴影（扁平化风格）或轻微外阴影（偏移 1pt，模糊 2pt，透明度 30%） |
| **文字对齐** | 居中对齐，垂直居中 |

### 2.2 模块尺寸参考

| 模块层级 | 宽度 | 高度 | 字号 |
|----------|------|------|------|
| **顶层模块**（整体网络框） | 8 ~ 12 cm | 2 ~ 3 cm | 14 ~ 16 pt |
| **中层模块**（子网络/Stage） | 4 ~ 6 cm | 1.2 ~ 1.8 cm | 11 ~ 13 pt |
| **底层模块**（具体操作：Conv/Pool/Attention） | 2 ~ 3 cm | 0.8 ~ 1.2 cm | 9 ~ 10 pt |
| **最小标签**（通道数、公式符号） | 1 ~ 1.5 cm | 0.5 cm | 8 pt |

### 2.3 箭头规范

| 箭头类型 | 线型 | 颜色 | 粗细 | 用途 |
|----------|------|------|------|------|
| **主数据流** | 实线 | `#6C7A89` | 1.5 pt | 主要数据流向 |
| **残差/跳跃连接** | 虚线（Dash: 3pt, Gap: 2pt） | `#95A5A6` | 1 pt | Skip Connection、残差分支 |
| **控制/门控信号** | 点划线 | `#B8956A` | 1 pt | 注意力权重、门控信号 |
| **反馈/循环** | 实线 + 弯曲 | `#A72A35` | 1 pt | 循环连接、反馈路径 |

## 四、分步绘制流程（以 SSFA-Net 为例）

### Step 1: 建立画布

1. 打开 PowerPoint，新建空白幻灯片
2. 设置幻灯片大小：**宽屏 16:9**（33.867 cm × 19.05 cm）
3. 背景色设为纯白 `#FFFFFF` 或极浅灰 `#FAFAFA`
4. 可选：添加 subtle grid（网格线间距 0.5 cm，颜色 `#F0F0F0`）辅助对齐

### Step 2: 划分面板（多面板布局）

| 面板 | 位置 | 内容 | 典型尺寸 |
|------|------|------|----------|
| **Panel 1** | 左上 | 总体架构 | 占 50% 宽度，占 55% 高度 |
| **Panel 2** | 右上 | 核心模块 A 内部 | 占 50% 宽度，占 55% 高度 |
| **Panel 3** | 左下 | 核心模块 B 内部 | 占 50% 宽度，占 45% 高度 |
| **Panel 4** | 右下 | 损失/输出 | 占 50% 宽度，占 45% 高度 |

使用 **细虚线框**（`#D5D8DC`，0.5 pt，虚线）划分四个面板区域。

### Step 3: 绘制总体架构（Panel 1）

```
输入图像 I [桃色 #F2CEB0]  →  3×3 Conv [绿色 #B0D194]
                                    ↓
                    ┌──────────────────────────────┐
                    │   Scale 1: H×W×C [绿色]      │ ← MSRBlock + SSA [粉色]
                    │        ↓                     │
                    │   Scale 2: H/2×W/2×2C [绿色] │ ← MSRBlock + SSA [粉色]
                    │        ↓                     │
                    │   Scale 3: H/4×W/4×4C [绿色] │ ← MSRBlock + SSA [粉色]
                    │        ↓                     │
                    │   Decoder + Skip [蓝色]      │
                    └──────────────────────────────┘
                                    ↓
                          DDSFA [粉色]  →  J = I + R [桃色]
```

**操作要点**：
- 编码器-解码器用 **大圆角矩形框** 包裹（填充无或浅灰 `#F8F9FA`，边框 `#D5D8DC`）
- 下采样用向下箭头 + `↓` 标签标注比例（`H/2×W/2`）
- Skip Connection 用 **虚线箭头** 从编码器指向解码器对应层

### Step 4: 绘制 SSA 模块内部（Panel 2）

```
X(N×C×H×W) [桃色] → Flatten → T(N×L×C) [米白]
                              ↓
              ┌───────────────┼───────────────┐
              ↓               ↓               ↓
        LSH Hashing    ARGSORT +     Energy Selection
        [粉色]         Partition      [粉色]
        (T·Rᵀ>0)       into G_h       (argmax ‖·‖_F)
                              ↓
                    Dense Guidance Map S [绿色]
                              ↓
                    1×1 Conv + Sigmoid [粉色]
                              ↓
            w_H, w_V (k-tap strip weights) [米白]
                              ↓
              ┌───────────────┴───────────────┐
              ↓                               ↓
        UNFOLD_H (k×1)                 UNFOLD_V (1×k)
        [蓝色]                           [蓝色]
              ↓                               ↓
              └───────────┬───────────────────┘
                          ↓
              γ ⊙ X_V + β ⊙ X [暗红 #A72A35]
                          ↓
                      Output Y [桃色]
```

**操作要点**：
- 每个 Step 用圆角矩形，内部标注操作名称和公式
- 公式用 Cambria Math 斜体，如 `T(N×L×C)`、`O(L log L)`
- 复杂操作（如 LSH Hashing）可用 **嵌套小矩形** 展开内部细节
- 复杂度标注用注释框（8pt，灰色，放在模块右下角）

### Step 5: 绘制 DDSFA 模块内部（Panel 3）

```
                          X [桃色]
                           ↓
              ┌────────────────────────────┐
              │     SA Branch [粉色]        │
              │  AvgPool+MaxPool+VarPool    │
              │       ↓                     │
              │   Conv3×3 + Dilated DWConv  │
              │       ↓                     │
              │   X_s = X_wide ⊙ T(A,C)    │
              └────────────────────────────┘
                           ↓
              ┌────────────────────────────┐
              │     FA Branch [淡紫 #C5B9CD] │
              │  GAP → X_sl(DC) [薄荷灰绿]  │
              │       ↓                     │
              │   X_sh = X_s - X̃_sl         │
              │   X_m = X̃_sl ⊙ X_s          │
              │       ↓                     │
              │  Concat → 1×1 Conv fusion   │
              └────────────────────────────┘
                           ↓
                        X̂ [桃色]
```

**操作要点**：
- SA 和 FA 两个分支用 **并列的圆角矩形框** 包裹
- 分支框的填充色比内部模块浅 20%（如 SA Branch 框用 `#FADBD8`，内部模块用 `#EA9D9D`）
- 输出公式 `X̂ = FA(SA(X))` 用 Bold 字体放在分支框下方

### Step 6: 绘制损失函数（Panel 4）

```
        ┌─────────────────────────────────────┐
        │            Loss Function [暗红]      │
        │                                     │
        │   L = L_spa + 0.01 · L_freq         │
        │                                     │
        │   L_spa = Σ ‖Ŷ_s - Y_s‖₁   [绿色]   │
        │        (Pixel L1, 3 scales)         │
        │                                     │
        │   L_freq = Σ ‖F(Ŷ_s) - F(Y_s)‖₁    │
        │        (FFT spectral L1, 3 scales)  │
        │              [淡紫 #C5B9CD]          │
        │                                     │
        └─────────────────────────────────────┘
```

**操作要点**：
- 损失函数用 **暗红色边框 + 浅红填充**（`#FDEDEC`）突出显示
- 公式中的希腊字母（α、Σ）用 Cambria Math
- FFT 图标可用小闪电符号 ⚡ 或波形符号标注

### Step 7: 添加图标题和图例

- **图标题**：放在顶部居中，18pt Bold，如 "SSFA-Net Architecture"
- **图例**：放在右下角或底部，用 1cm × 0.5cm 的小色块 + 文字说明

```
图例:
[■ #F2CEB0] 输入/输出  [■ #B0D194] 特征提取  [■ #EA9D9D] 注意力/核心
[■ #385492] 融合/解码  [■ #A72A35] 损失/残差  [■ #C5B9CD] 频域处理
```

## 五、PPT 快捷键与技巧

| 操作 | 快捷键/方法 |
|------|------------|
| **快速复制模块** | Ctrl + D（带偏移复制），Ctrl + Shift + D（原位复制） |
| **等间距排列** | 选中多个 → 格式 → 对齐 → 横向/纵向分布 |
| **统一修改颜色** | 选中形状 → 右键设置形状格式 → 填充 → 更多颜色 → 输入 HEX |
| **精确调整大小** | 右键 → 大小和位置 → 直接输入厘米数值 |
| **组合复杂模块** | Ctrl + G（组合），方便整体移动 |
| **对齐到网格** | 视图 → 网格线 → 勾选"对齐到网格" |
| **批量改字体** | 开始 → 替换 → 替换字体 |
| **导出高清图** | 文件 → 另存为 → 选择 PNG/JPEG → 仅当前幻灯片 → 分辨率 300 dpi |

## 六、常见错误与避免方法

| 错误 | 正确做法 |
|------|----------|
| 颜色饱和度过高 | 使用莫兰迪色系，避免纯红 `#FF0000`、纯蓝 `#0000FF` |
| 模块大小参差不齐 | 先画一个标准模块，复制后只改文字和颜色 |
| 箭头交叉混乱 | 使用正交箭头（先水平后垂直），或增加留白间距 |
| 文字过小看不清 | 最小字号 8pt，重要模块至少 10pt |
| 缺少通道/尺寸标注 | 在数据流箭头旁标注 `C×H×W` 或 `N×L×C` |
| 一个面板塞太多内容 | 超过 8 个模块就拆分为两个子面板 |
| 边框太粗喧宾夺主 | 统一使用 1pt 细边框，只在需要强调的模块用 1.5pt |

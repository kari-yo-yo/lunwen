## 一、核心问题

### 1.1 图像去雨的挑战

单图像去雨 (Single Image Deraining, SID) 是一个经典的低层视觉任务，旨在从给定的带雨图像中恢复清晰的高质量图像。由于该任务本质上是不适定的 (ill-posed)，存在无穷多可能的解，因此设计有效的去雨模型极具挑战性。

### 1.2 不规则雨纹和复杂几何重叠的挑战

传统方法基于雨纹的统计特征和先验知识进行去雨，但在复杂多样的雨场景中，这些先验并不总是成立。基于深度学习的方法虽然取得了显著进步，但仍面临以下关键挑战：

**不规则雨纹 (Irregular Rain Patterns)**：
- 雨纹的形状、方向、密度、粗细变化多样，没有固定的模式可循。
- 传统的周期性假设（如雨纹是竖直的线性结构）在真实场景中常常不成立。
- 自注意力机制中的低注意力值 token 或无关 token 会在密集注意力矩阵中引入干扰，损害输出特征质量。

**复杂几何重叠 (Complex Geometric Overlaps)**：
- 多层雨纹相互叠加，形成复杂的退化模式。
- 雨纹与背景纹理相互缠绕，使得简单的前景-背景分离难以奏效。
- 雨纹可能在某些区域与背景特征高度相似，增加了区分难度。

### 1.3 单范式架构的局限

现有去雨 Transformer 方法主要从两个范式中选择其一进行建模，但均存在不足：

1. **空间-通道范式**（Spatial-Channel Paradigm）：
   - 空间自注意力（如 IDT 的窗口注意力）：捕获像素间的长距离依赖，但计算开销大。
   - 通道自注意力（如 Restormer、DRSformer）：沿通道维度计算注意力，计算高效但忽略了空间信息。
   - DAT 交替使用空间和通道注意力，但缺乏统一的融合框架。

2. **全局-局部范式**（Global-Local Paradigm）：
   - CNN 擅长局部特征提取，Transformer 擅长全局建模。
   - 一些混合模型（如 HCT-FFN、SMFANet）尝试结合两者，但通常是简单的拼接或相加，缺乏深层的特征交互和对齐。

**关键问题**：现有方法要么只利用了一种范式，要么简单地组合两种范式，缺乏一个统一框架来有效整合空间-通道和全局-局部的互补表征。

## 二、核心方法

### 2.1 4 级编解码器架构

CPRAformer 采用 4 级编码器-解码器架构，带有跳跃连接。

```
输入雨图像 I_rain (H x W x 3)
    |
  7x7 卷积 → 低级特征嵌入 F_0 (H x W x C)
    |
  编码器 Stage 1 (N1 个 CPRAformerB) → 下采样
  编码器 Stage 2 (N2 个 CPRAformerB) → 下采样
  编码器 Stage 3 (N3 个 CPRAformerB) → 下采样
  编码器 Stage 4 (N4 个 CPRAformerB)
    | (跳跃连接)
  解码器 Stage 4 (N4 个 CPRAformerB) → 上采样
  解码器 Stage 3 (N3 个 CPRAformerB) → 上采样
  解码器 Stage 2 (N2 个 CPRAformerB) → 上采样
  解码器 Stage 1 (N1 个 CPRAformerB)
    |
  3x3 卷积 → 输出去雨图像
```

**设计特点**：
- 编码器逐步降低分辨率（2x 下采样），同时增加通道数，提取多尺度抽象特征。
- 解码器逐步恢复分辨率，重建图像细节。
- 跳跃连接将编码器的浅层特征传递到对应的解码器层，保留低级细节信息。
- 每个 CPRAformerB（CPRAformer Block）包含核心的 CPIA-SA 和 MSGN 模块。

### 2.2 SPC-SA：稀疏提示通道自注意力 (Sparse Prompt Channel Self-Attention)

#### 2.2.1 核心思想

SPC-SA 沿**通道维度**计算自注意力，建立全局通道依赖关系。然而，密集的注意力矩阵中存在大量低注意力值的 token，这些 token 之间的交互不仅不提供有用信息，反而会引入噪声干扰，降低图像恢复质量。因此，SPC-SA 引入**稀疏提示机制**，动态过滤掉低注意力值的 token。

#### 2.2.2 具体实现

1. **通道自注意力计算**：将输入特征在通道维度上计算 Query、Key、Value，通过注意力机制建立全局通道依赖：
   - Q, K, V 均通过线性投影获得。
   - 注意力矩阵 A = softmax(Q * K^T / sqrt(d))。
   - 输出 = A * V。

2. **稀疏提示过滤**：利用提示信息 (Prompt Information) 动态过滤注意力矩阵中的低值 token：
   - **提示信息**：基于注意力矩阵的统计特性（如注意力值的分布）生成的提示信号。
   - **动态过滤**：低于某阈值的注意力值被置零或降低，减少无意义的交互。
   - **可学习算子**：使用可学习的参数调整稀疏范围（即决定多少比例的 token 被过滤），而非使用固定阈值。

3. **稀疏注意力的优势**：
   - 保留了最重要的通道间依赖关系（高注意力值的 token 交互）。
   - 移除了噪声性的低注意力值交互，避免了过度干扰。
   - 可学习的稀疏范围使网络能够自适应地决定每层的稀疏程度。

#### 2.2.3 全局信息提取

SPC-SA 的通道维度自注意力天然具有全局感受野（每个通道 token 包含整个空间位置的信息），因此能够高效地建立全局通道依赖，为后续的局部细化提供全局上下文信息。

### 2.3 SPR-SA：空间像素细化自注意力 (Spatial Pixel Refinement Self-Attention)

#### 2.3.1 核心思想

SPR-SA 的目标是在**空间维度**上建模局部细粒度特征和相邻空间像素之间的关系。与标准的空间自注意力（计算复杂度高）不同，SPR-SA 使用**高效的 CNN 近似自注意力**，在保持建模能力的同时大幅降低计算开销。

#### 2.3.2 具体实现

1. **CNN 近似自注意力**：
   - 标准自注意力的 Query-Key 相互作用等价于一种非局部操作。
   - SPR-SA 使用深度可分离卷积 (Depthwise Separable Convolution) 和逐点卷积 (Point-wise Convolution) 来近似这种非局部交互。
   - 这种设计保留了自注意力建模空间依赖的能力，同时具有 CNN 的高效性。

2. **局部细粒度特征建模**：
   - SPR-SA 专注于空间域中的局部特征——雨纹的形状、方向、密度等细粒度信息。
   - 相邻像素之间的关系（如雨纹的连续性、背景纹理的平滑性）通过卷积操作有效建模。

3. **互补性**：
   - SPC-SA 提供全局通道上下文信息 → 扩展 SPR-SA 中每个像素的感受野。
   - SPR-SA 增强每个特征图的空间表征 → 反过来帮助 SPC-SA 更好地建模通道上下文。

### 2.4 AAFM：自适应对齐频率模块 (Adaptive Alignment Frequency Module)

AAFM 是 CPRAformer 中处理**跨范式特征对齐**的核心模块，采用**两阶段渐进融合策略**。

#### 2.4.1 阶段一：自适应加权对齐 (Adaptive Weighted Alignment)

**问题**：SPC-SA（通道维度，全局信息）和 SPR-SA（空间维度，局部细节）提取的特征来自不同的范式，直接相加或拼接会导致信息丢失和特征不对齐。

**解决方案**：通过自适应加权对齐减少两个分支之间的信息差距。

1. 对 SPC-SA 和 SPR-SA 的输出特征分别计算自适应权重。
2. 根据每个位置的贡献度，动态调节两个分支特征的融合比例。
3. 自适应加权使得两个范式的特征在融合前被"拉齐"到相似的信息水平，减少信息差距。

#### 2.4.2 阶段二：频域交互融合 (Frequency-Domain Interaction Fusion)

**问题**：仅通过空间域的加权对齐难以充分利用特征之间的深层交互关系。

**解决方案**：将特征变换到频域，在频域中进行交互和融合。

1. 对对齐后的特征进行 FFT 变换，转换到频域。
2. 在频域中进行特征交互（如频域中的注意力、逐元素操作等）。
3. 频域交互能够捕获空间域中不易建模的全局频率关系。
4. 逆变换回空间域，得到最终的对齐融合特征。

#### 2.4.3 两阶段渐进融合的必要性

**为什么不能一步到位？**
- 如果直接在频域融合，两个分支的特征差距过大（一个是全局通道信息，一个是局部空间信息），频域交互的效果会被特征不对齐所削弱。
- 第一阶段的自适应加权先"缩小差距"，使两个分支的特征达到一个相对一致的水平。
- 第二阶段的频域交互再"深度融合"，在差距缩小的基础上进行有效的特征交互。
- 渐进策略确保了融合的有效性和稳定性。

### 2.5 MSGN：多尺度流门控网络 (Multi-Scale Flow Gating Network)

#### 2.5.1 核心思想

在标准 Transformer 中，前馈网络 (FFN) 通常通过全连接层提取特征，但忽略了低层视觉任务中至关重要的**多尺度信息**。MSGN 通过门控机制引入多尺度表征，替代标准 FFN。

#### 2.5.2 具体实现

1. **多尺度特征提取**：使用不同膨胀率 (Dilation Rate) 的卷积核提取多尺度特征，捕获不同大小的雨纹和背景结构。
2. **流门控机制**：通过门控单元（类似 LSTM/GRU 中的门控）控制不同尺度特征的流通。门控信号根据特征内容动态决定哪些尺度的信息需要传递到下一层。
3. **替代 FFN**：MSGN 被嵌入到每个 CPRAformerB 中，替代标准的 FFN，为 Transformer 模块提供额外的多尺度非线性信息。

#### 2.5.3 MSGN 的优势

- 雨纹的大小变化多样，单一尺度的特征提取难以覆盖所有情况。
- 门控机制提供了自适应的能力，网络可以根据输入内容选择性地利用不同尺度的信息。
- 作为 FFN 的替代，MSGN 在不显著增加计算量的前提下增强了特征提取能力。

### 2.6 CPIA-SA 整体机制

CPIA-SA（Cross Paradigm Interaction and Alignment Self-Attention）是 CPRAformer 的核心 Transformer 块，将上述组件有机整合：

```
输入特征
    |
  ├── SPC-SA (稀疏提示通道自注意力)
  |     → 全局通道依赖，动态稀疏过滤
  |
  ├── SPR-SA (空间像素细化自注意力)
  |     → 局部空间细节，CNN近似自注意力
  |
  ├── AAFM (自适应对齐频率模块)
  |     → 阶段一：自适应加权对齐
  |     → 阶段二：频域交互融合
  |
  └── MSGN (多尺度流门控网络，替代标准FFN)
        → 多尺度特征提取 + 门控流通
```

**整体工作流程**：
1. SPC-SA 从通道维度提取全局上下文信息，通过稀疏提示过滤降低噪声干扰。
2. SPR-SA 在空间维度上建模局部细节，SPC-SA 的全局信息为其扩展感受野。
3. AAFM 对两个分支的特征进行两阶段渐进对齐融合，先缩小信息差距，再在频域深度融合。
4. MSGN 在 FFN 位置引入多尺度信息，进一步增强特征表征能力。

## 三、损失函数

CPRAformer 使用 **Charbonnier 损失函数** 作为主要的训练损失：

$$\mathcal{L} = \sqrt{(I_{out} - I_{GT})^2 + \epsilon^2}$$

其中 $I_{out}$ 是去雨输出，$I_{GT}$ 是干净真实图像，$\epsilon$ 是平滑常数。

**损失函数的特点**：
- Charbonnier 损失是 L1 损失的平滑近似，对异常值更加鲁棒。
- 在图像重建和去雨任务中被广泛采用，是一种稳健的像素级重建损失。
- 论文未引入额外的复杂损失函数（如感知损失、对抗损失等），表明模型架构本身已经足够强大。

## 四、实验结果

### 4.1 评估基准

CPRAformer 在 **8 个基准数据集**上进行了全面评估，包括：

- 合成雨数据集：Rain100H, Rain100L, Rain1200, Rain14000, Test100, Test120
- 真实世界数据集：Internet-Data, SPA-Data
- 其他图像恢复任务（验证泛化能力）：去噪、去雾、去模糊等

### 4.2 与 SOTA 方法的比较

CPRAformer 在所有 8 个基准数据集上均达到 SOTA 性能，超越了以下代表性方法：

| 方法 | 类型 | 关键特点 |
|------|------|---------|
| Restormer | Transformer | 通道自注意力 |
| DRSformer | Transformer | 稀疏通道自注意力 |
| IDT | Transformer | 窗口+空间双注意力 |
| DAT | Transformer | 双注意力交替 |
| TransMamba | 混合 | Transformer+Mamba |
| MPRNet | CNN | 多阶段渐进恢复 |
| SPDNet | CNN | 语义优先去雨 |

**关键优势**：
- **PSNR/SSIM 全面领先**：在合成数据集上，PSNR 和 SSIM 均取得最优结果。
- **真实场景表现优异**：在 Internet-Data 和 SPA-Data 上的视觉效果显著优于其他方法。
- **泛化能力强**：在其他图像恢复任务（去噪、去雾、去模糊）上也展现了强大的性能，证明了跨范式的表征能力不仅限于去雨任务。

### 4.3 下游应用验证

论文还验证了 CPRAformer 在下游任务中的实用性，如目标检测等，证明了去雨质量对高级视觉任务的积极影响。

## 五、消融实验

### 5.1 SPC-SA（稀疏提示通道自注意力）的贡献

- 将 SPC-SA 替换为标准通道自注意力：性能下降。
- 移除稀疏提示机制：性能下降。
- 表明：稀疏提示过滤对于去除注意力矩阵中的噪声交互至关重要，动态稀疏比固定稀疏更有效。

### 5.2 SPR-SA（空间像素细化自注意力）的贡献

- 将 SPR-SA 替换为标准空间自注意力：性能下降（同时计算量增加）。
- 移除 SPR-SA：性能显著下降。
- 表明：高效的 CNN 近似自注意力不仅降低了计算开销，而且在建模局部空间细节方面同样有效。

### 5.3 AAFM（自适应对齐频率模块）的贡献

- 移除 AAFM，使用简单相加融合：性能下降。
- 仅使用阶段一（自适应加权），不使用阶段二（频域交互）：性能下降。
- 仅使用阶段二，不使用阶段一：性能下降更多。
- 表明：两阶段渐进融合策略是必要的。第一阶段缩小信息差距是第二阶段深度融合的前提。

### 5.4 MSGN（多尺度流门控网络）的贡献

- 将 MSGN 替换为标准 FFN：性能下降。
- 表明：多尺度信息对于覆盖不同大小的雨纹和背景结构至关重要，门控机制提供了自适应的选择能力。

### 5.5 各组件综合消融

| 配置 | PSNR | SSIM |
|------|------|------|
| 完整 CPRAformer | 最佳 | 最佳 |
| -SPC-SA | 下降 | 下降 |
| -SPR-SA | 下降 | 下降 |
| -AAFM | 下降 | 下降 |
| -MSGN | 下降 | 下降 |
| 标准融合替代 AAFM | 下降 | 下降 |

## 六、深度分析

### 6.1 为什么需要跨范式对齐？

**多范式互补性**：

在图像去雨任务中，以下两个范式的信息都是必要的：
1. **空间-通道范式**：通道维度捕获全局语义上下文（哪些通道包含雨纹信息、哪些包含背景信息），空间维度捕获局部细节（雨纹的形状、位置、方向）。
2. **全局-局部范式**：全局依赖帮助识别分布在不同位置的相似雨纹模式，局部特征帮助恢复精细的纹理和边缘。

**为什么简单融合不够？**

- **特征不对齐**：空间维度特征和通道维度特征处于不同的"信息空间"，直接相加或拼接会导致信息冲突。例如，通道注意力可能放大某些通道的雨纹信息，而空间注意力可能在对应区域保留雨纹细节——两者的信号可能相互矛盾。
- **知识差异**：不同范式提取的特征具有不同的统计特性和语义级别，简单融合会丢失这些差异中蕴含的有用信息。
- **信息间隙**：AAFM 的两阶段渐进融合专门设计来"弥合"这种间隙，先对齐再融合。

### 6.2 SPC-SA 的稀疏提示怎么工作？

**密集注意力矩阵的问题**：

在标准自注意力中，每个 token 都会与所有其他 token 计算注意力。然而，对于通道维度自注意力：
- 一些通道与当前任务高度相关（如包含雨纹颜色信息的通道）。
- 一些通道与当前任务弱相关甚至无关（如包含背景纯色信息的通道）。
- 无关通道之间的注意力交互产生的是噪声，不提供有用信息，反而可能干扰相关通道的特征表达。

**稀疏提示的机制**：

1. **提示信息生成**：基于注意力矩阵的统计分布（如均值、方差），生成一个"提示信号"，指示哪些位置的注意力值可能是有用的，哪些可能是噪声。
2. **动态阈值**：使用可学习的参数（而非固定阈值）确定稀疏范围。这使得不同层、不同输入可以有不同稀疏程度。
3. **选择性过滤**：低注意力值的 token 被过滤掉（置零或大幅降低权重），只有高注意力值的 token 参与后续计算。

**效果**：
- 保留了最关键的通道间依赖关系。
- 减少了无意义的通道交互噪声。
- 提高了计算效率（稀疏矩阵乘法比密集矩阵乘法更快）。

### 6.3 AAFM 两阶段渐进融合的必要性

**如果只做空间域融合（无频域）**：
- 空间域的融合只能建模局部特征关系，无法捕获频域中的全局结构信息。
- 特征对齐在空间域中是有限的——空间域中"对齐"更多是幅度上的，而非结构上的。

**如果直接做频域融合（无预对齐）**：
- SPC-SA 和 SPR-SA 的特征在频域中的分布差异很大（一个是通道信息，一个是空间信息），直接频域交互会放大差异而非缩小它。
- 就像让两个说不同语言的人直接讨论——没有翻译（预对齐），无法有效交流。

**两阶段策略的优势**：
1. **阶段一（自适应加权）**：像"翻译"——将两种范式特征的信息量调节到相近的水平，消除"语言障碍"。
2. **阶段二（频域交互）**：像"深度讨论"——在信息量对齐的基础上，在频域中进行深层特征交互和融合，充分利用频域的全局性质。

---

## 七、Baseline 改善点

### 7.1 相对于纯通道自注意力方法（Restormer, DRSformer）

| 改善点 | 说明 |
|--------|------|
| 空间维度建模 | SPR-SA 补充了通道自注意力缺失的空间建模能力 |
| 稀疏注意力 | 稀疏提示机制减少了通道注意力的噪声干扰 |
| 跨范式对齐 | AAFM 实现了通道-空间特征的有效对齐融合 |

### 7.2 相对于混合方法（TransMamba, HCT-FFN, SMFANet）

| 改善点 | 说明 |
|--------|------|
| 统一框架 | CPRAformer 提供了统一的跨范式框架，而非简单的分支拼接 |
| 渐进融合 | AAFM 的两阶段渐进融合比简单拼接/相加更有效 |
| 多尺度信息 | MSGN 替代 FFN 引入多尺度表征，增强特征提取 |
| 频域对齐 | 利用频域进行特征交互，充分利用全局频率信息 |

### 7.3 核心创新总结

1. **跨范式表征学习框架**：首次统一整合空间-通道和全局-局部两种范式，建立完整的跨范式特征提取和对齐框架。
2. **稀疏提示机制**：动态自适应地调整稀疏范围，避免固定稀疏率的限制。
3. **AAFM 两阶段渐进融合**：自适应加权对齐 + 频域交互融合，有效弥合跨范式特征间隙。
4. **MSGN 多尺度门控网络**：以门控机制替代标准 FFN，引入多尺度信息。

## 八、不足与局限

### 8.1 计算复杂度

CPRAformer 包含多个复杂模块（SPC-SA、SPR-SA、AAFM、MSGN），整体模型参数量和计算量较大。双注意力 + 频域变换 + 多尺度卷积的设计使得推理速度可能不如更轻量的方法。

### 8.2 架构复杂度高

- 模块众多且相互依赖（SPC-SA 为 SPR-SA 提供全局信息，AAFM 对齐两者，MSGN 增强 FFN），增加了设计和调优的难度。
- 消融实验虽然验证了每个组件的贡献，但各组件之间的最佳配置和超参数选择需要大量实验。

### 8.3 频域交互的理论支撑

- AAFM 的频域交互融合虽然有效，但论文中对频域交互为什么能有效弥合跨范式特征间隙的理论分析不够深入。
- FFT 变换的周期性假设与自然图像的非周期性之间的矛盾未做详细讨论。

### 8.4 对极重度雨纹的泛化

- 虽然在标准数据集上表现优异，但对于极端雨场景（如暴雨、多重雨纹叠加、雨纹与雾同时存在等）的泛化能力未做专门验证。
- 论文主要关注单雨纹类型去除，对复合退化场景的处理能力有待进一步研究。

### 8.5 真实世界数据的限制

- 真实世界雨图像缺乏精确的 ground truth，定量评估主要依赖合成数据。
- 在真实图像上的性能验证主要是视觉对比，缺乏用户研究或人类感知评估。

### 8.6 与扩散模型的比较

- 论文未与基于扩散模型 (Diffusion Model) 的图像恢复方法进行对比。扩散模型近年来在图像恢复任务中展现了强大的生成能力，作为基线对比是有价值的。

---

## 九、一句话总结

CPRAformer 通过稀疏提示通道自注意力 (SPC-SA) 提取全局通道依赖，空间像素细化自注意力 (SPR-SA) 捕获局部空间细节，自适应对齐频率模块 (AAFM) 以两阶段渐进策略弥合跨范式特征间隙，并配合多尺度流门控网络 (MSGN) 替代标准 FFN，构建了首个统一整合空间-通道与全局-局部双重范式的图像去雨框架，在 8 个基准数据集上全面达到 SOTA。

## 十、生活化例子：翻译团队类比

想象一个国际翻译团队需要将一篇复杂的中文论文翻译成英文，CPRAformer 的工作方式就像这个团队的高效协作流程：

**SPC-SA = 通才翻译（全局理解大意）**

- 通才翻译快速浏览整篇论文，理解每个章节的**核心主旨和大意**（全局通道依赖）。
- 他不需要逐字逐句阅读，而是关注各章节之间的**逻辑关系**（通道间的高注意力值交互）。
- 但他有一个聪明的工作方式——**稀疏提示**：他只深入阅读最有价值的部分，跳过那些对整体理解贡献不大的冗余段落（过滤低注意力值的噪声交互）。
- 可学习的稀疏范围就像他能根据论文的难度**动态调整**阅读深度——简单的部分快速跳过，复杂的部分仔细研读。
- 最终，他产出了一份包含**全局上下文信息**的摘要。

**SPR-SA = 专业翻译（逐字精准翻译）**

- 专业翻译负责**逐字逐句**的精准翻译工作（局部空间细节）。
- 他关注每个词语的**精确含义**、句子结构、修辞手法等细粒度信息（相邻像素间的关系）。
- 虽然他不像通才翻译那样有全局视野，但他使用**高效的工具**（CNN 近似自注意力）来加速翻译过程——利用词典、翻译记忆库等工具，而不是每次都从头分析。
- 通才翻译提供的全局摘要为他提供了**上下文参考**（SPC-SA 扩展 SPR-SA 的感受野），帮助他在遇到歧义时做出正确的翻译选择。

**AAFM = 编辑（确保两种翻译风格对齐融合）**

- 编辑负责将通才翻译的"大意版"和专业翻译的"精准版"进行**对齐和融合**。
- **阶段一（自适应加权对齐）**：编辑先检查两份译稿，发现它们在风格和详略程度上差异很大。于是，他**动态调节**两份译稿的融合比例——在某些章节偏向通才翻译的简洁风格，在另一些章节偏向专业翻译的详尽风格，使两份译稿达到"相似的详细程度"（缩小信息差距）。
- **阶段二（频域交互融合）**：然后，编辑将两份已对齐的译稿放在一起，从**更高层次**（频域）审视它们的结构和逻辑关系。他检查两份译稿的**段落结构、论证逻辑**是否一致（频域交互），并在此基础上进行深度融合，产生最终的统一译稿。
- **为什么需要两阶段？** 如果直接把两份差异巨大的译稿混在一起，结果会很混乱（直接频域融合无效）。只有先让两份译稿"风格对齐"（阶段一），才能有效地进行深度融合（阶段二）。

**MSGN = 审校员（多尺度质量把控）**

- 审校员从**多个角度**审查最终译稿的质量（多尺度特征提取）：
  - 整体结构是否通顺？（大尺度）
  - 段落衔接是否自然？（中尺度）
  - 用词是否准确？（小尺度）
- 他使用**门控机制**决定哪些方面需要重点修改——如果整体结构已经很好，就把精力放在用词上；如果用词已经很准确，就重点关注段落衔接（自适应多尺度选择）。
- 这种多尺度审校比单一的通读检查（标准 FFN）更全面、更有效。

**整体协作效果**：通才翻译提供全局视野 → 专业翻译提供精准细节 → 编辑对齐融合两种风格 → 审校员从多角度确保质量。最终产出的译稿既准确又流畅，就像 CPRAformer 的去雨图像既去除了雨纹又保持了纹理细节。

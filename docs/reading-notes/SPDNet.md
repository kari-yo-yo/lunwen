## 二、痛点分析

| 痛点编号 | 痛点描述 | 深层原因 | 现有方案不足 |
|----------|----------|----------|-------------|
| **P1** | 现有方法难以恢复结构清晰准确的无雨图像 | 去雨过程容易破坏纹理和边缘 | CNN方法在细节保持上不足 |
| **P2** | 依赖雨生成假设，真实场景泛化差 | 合成雨模型与真实雨存在域差距 | 不依赖假设的方法更鲁棒 |
| **P3** | 高频雨纹与高频边缘信息纠缠 | 频域中雨纹和边缘重叠 | 需要先验知识辅助分离 |

---

## 三、核心方法

### 3.1 残差通道先验 (RCP)

**关键发现**: 图像的残差通道（RGB通道间的关系/差值）包含比有雨图像更准确的结构信息。

```
RCP = RGB通道间的关系编码
├── 有雨图像的RCP: 受雨纹干扰但保留了大致结构
├── 无雨图像的RCP: 干净且准确的结构信息
└── RCP的差值比原始图像的差值更能指导结构恢复
```

### 3.2 小波多级模块 (WMLM)

- 利用小波变换将图像分解为低频和高频分量
- 低频分支学习背景结构信息
- 高频分支处理边缘和纹理细节

### 3.3 交互融合模块 (IFM)

```
RCP特征 ──→ [交互融合] ←── 骨干特征
                │
                ▼
          增强后的特征
```

- 充分利用RCP信息与骨干网络特征进行交互融合
- RCP指导网络关注结构保持区域

### 3.4 迭代引导策略

- 逐步提升RCP的准确性
- 通过渐进路径精炼去雨结果
- 每次迭代RCP估计更加准确

## 五、总结与启发

1. **RCP 先验**是从数据本身挖掘结构信息的经典思路，不依赖外部模型假设
2. **迭代精炼**策略在逐步提升估计精度方面非常有效
3. 小波变换与深度学习的结合在图像恢复任务中表现优秀
4. RCP思想可迁移到其他需要结构保持的图像恢复任务（去雾、去雪等）

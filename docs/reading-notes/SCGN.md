> **作者**: Hesong Li, Ziqi Wu, Ruiwen Shao, Ying Fu (北京理工大学)
> **代码**: https://github.com/HeasonLee/SCGN

## 一、论文核心问题与动机

### 1.1 研究背景

高分辨率透射电子显微镜 (HRTEM) 能够在原子尺度上观察成核动力学过程，这对于研究先进固体材料（如石墨烯、金刚石、金属催化剂）的形成机制具有至关重要的意义。然而，成核过程通常在毫秒级别发生快速变化，因此需要极短的曝光时间进行快速成像。短曝光导致图像信噪比极低，原子位置被严重噪声淹没，使得准确识别原子排列变得极具挑战性。

### 1.2 现有方法的不足

**网络设计层面的问题：**

- 现有原子图像去噪方法（如 AtomSegNet、SFIN）通常对整个空间或频率域的特征执行统一处理，在面对无序结构快速成像时，难以有效区分信号与噪声。
- 传统去噪方法（高斯滤波、维纳滤波、双边滤波）在极低信噪比下几乎完全失效。
- 现有深度学习方法主要面向有序晶格结构的去噪，对成核过程中无序到半无序结构的去噪效果有限。

**数据层面的严重缺口：**

1. **缺乏无序结构数据集**：现有数据集（如 TEMImageNet）主要包含完全有序的晶格结构原子排列，而缺少成核过程所需的无序或半无序原子结构。
2. **噪声分布不一致**：现有数据集的噪声参数通常是随机设定的，未经过标定。虽然 SFIN 数据集对 STEM（扫描透射电子显微镜）图像进行了噪声标定，但由于成像原理不同，HRTEM 与 STEM 的噪声类型和分布存在本质差异：
   - **HRTEM 特有噪声**：具有"列噪声"（Column Noise），而 STEM 不存在。
   - **STEM 特有噪声**：具有"扫描噪声"（Scan Noise），而 HRTEM 不存在。
   - 直接使用 STEM 噪声模型训练的模型在 HRTEM 真实图像上表现不佳。

### 1.3 核心动机总结

本论文的核心动机可归结为两点：
1. **设计层面**：利用统计特征（而非统一的卷积操作）引导网络区分信号与噪声，在空间域和频率域分别进行差异化处理。
2. **数据层面**：针对 HRTEM 开发专用的噪声标定方法，并生成包含无序结构和真实噪声的数据集，确保模型在真实成核观测场景中的泛化能力。

## 二、核心方法

### 2.1 整体架构

SCGN 网络采用简洁而有效的设计，整体架构如下：

```
输入 I_noisy (H x W x 1)
    |
  3x3 卷积 → 浅层特征提取 (C 通道)
    |
  n 个空间-频率增强块 (Spatial-Frequency Enhancement Block) + 残差连接
    |  ├── 空间域分支: 空间偏差引导加权模块 (执行 2 次增强)
    |  └── 频率域分支: 频率带引导加权模块 (执行 2 次增强)
    |  └── 通道维度拼接 + 3x3 卷积融合
    |
  3x3 卷积 → 输出 I_clean (H x W x 1)
```

**设计思路**：原子排列的周期性在频率域形成强信号，容易与噪声区分；而空间域则有利于恢复图像不同区域的局部特征。因此，网络将特征等分为两路（各 C/2 通道），分别在空间域和频率域进行增强，最后融合。

### 2.2 空间偏差引导加权 (Spatial Deviation-Guided Weighting)

#### 2.2.1 核心思想

HRTEM 图像中，不同空间位置的信号和噪声表现出不同的波动特性。例如，原子中心位置（信号强）与原子间距较大的区域（主要是噪声）的局部统计特征存在显著差异。因此，论文提出根据空间偏差特征为每个位置动态选择合适的卷积操作。

#### 2.2.2 具体实现

1. **空间偏差特征计算**：在 3x3 窗口内计算像素的标准差 (Standard Deviation, SD)，作为空间偏差特征。标准差反映了局部区域的波动程度：
   - SD 值较低的区域：可能是均匀噪声区域（无明显信号），需要平滑去噪。
   - SD 值较高的区域：可能包含原子信号（信号带来的局部强度变化），需要保留边缘和细节。

2. **动态权重生成**：基于 SD 特征通过学习生成权重，动态调节卷积操作的强度或类型。高偏差区域（含原子信号）倾向于保留更多细节，低偏差区域（纯噪声区域）倾向于更强的平滑。

3. **灵感来源**：受传统 Yau-Yau 滤波器启发。Yau-Yau 滤波器是一种非线性滤波算法，能够基于信号和噪声的统计特征有效提取非线性系统中的信号。SCGN 将这一思想迁移到深度学习框架中，用可学习的统计特征引导替代手工设计的滤波规则。

#### 2.2.3 为什么用 3x3 窗口？

3x3 窗口是计算局部统计特征的最小有效邻域。对于原子级图像，原子直径通常对应若干像素，3x3 窗口足以捕获单个原子附近的局部波动，同时保持计算效率。

### 2.3 频率带引导加权 (Frequency Band-Guided Weighting)

#### 2.3.1 核心思想

在频率域中，信号和噪声通常分布在不同频率带上：
- **低频带**：包含原子排列的周期性信号（原子晶格形成的规则模式）。
- **高频带**：主要包含噪声（随机分布、无周期性）。

因此，可以根据频率带特征，增强低频信号成分、抑制高频噪声成分。

#### 2.3.2 具体实现

1. **频率变换**：使用快速傅里叶变换 (FFT) 将图像特征从空间域转换到频率域。
2. **频率带特征提取**：在频率域中，不同频率带位置包含不同类型的信息。论文根据频率带的位置和内容生成动态权重。
3. **频率域增强**：基于频率带特征进行加权操作，对包含信号的低频带进行增强，对包含噪声的高频带进行抑制。
4. **逆变换**：处理后将特征转换回空间域，与空间域分支的结果融合。

#### 2.3.3 频率域处理的优势

- 原子排列的周期性在频率域形成明显的峰值，与噪声的频率分布有本质区别。
- 频率域处理可以直接针对特定频率带操作，避免空间域中信号与噪声混合导致的模糊处理。
- 对于晶格结构（尤其是半有序结构），频率域的周期性信号特征尤为突出。

### 2.4 HRTEM 噪声标定方法

#### 2.4.1 HRTEM vs STEM 噪声差异

| 噪声类型 | HRTEM | STEM |
|---------|-------|------|
| 成像方式 | 全局衍射成像（并行） | 逐像素扫描成像（串行） |
| 扫描噪声 | 无（不扫描） | 有（扫描过程引入） |
| 列噪声 | 有（探测器列间差异） | 无 |
| 散粒噪声 | 有 | 有 |
| 电子剂量噪声 | 有 | 有 |

#### 2.4.2 标定流程

1. 从真实 HRTEM 图像中估计噪声参数（均值、方差、分布类型等）。
2. 将标定后的噪声参数应用于模拟的干净原子图像。
3. 使用 abTEM 库或 ReciPro 软件生成包含无序原子排列的干净 HRTEM 图像作为 ground truth。
4. 添加标定后的真实噪声，生成训练样本。

#### 2.4.3 数据集特点

- 包含无序和半无序原子结构（模拟成核过程）。
- 噪声分布与真实 HRTEM 图像一致（经过标定）。
- 可同时用于合成数据训练和真实数据验证。

## 三、损失函数

SCGN 使用 **Charbonnier 损失函数** 作为训练损失。Charbonnier 损失是 L1 损失的一种平滑近似，对异常值更加鲁棒：

$$\mathcal{L} = \sqrt{(I_{clean} - I_{GT})^2 + \epsilon^2}$$

其中 $I_{clean}$ 是网络输出的去噪图像，$I_{GT}$ 是 ground truth 干净图像，$\epsilon$ 是一个小的常数（通常取 $10^{-3}$）以确保数值稳定性。

**选择 Charbonnier 损失的理由**：
- 相比 L2 损失，对异常值更鲁棒（不会过度惩罚大的误差）。
- 相比 L1 损失，处处可导，梯度更平滑，有利于优化过程的稳定性。
- 在图像重建和去噪任务中被广泛证明有效。

## 四、实验结果

### 4.1 合成数据实验

- **数据集**：使用论文提出的 HRTEM 标定噪声数据集进行训练和评估。
- **评估指标**：PSNR（峰值信噪比）、SSIM（结构相似性）。
- **结果**：在合成数据上，SCGN 显著优于现有 SOTA 方法（如 AtomSegNet、SFIN、UDVD 等），PSNR 和 SSIM 均有明显提升。

### 4.2 真实数据实验

- **数据来源**：真实的 HRTEM 快速成像数据，用于成核过程观测。
- **视觉评估**：SCGN 去噪后的图像能清晰显示原子位置，原子轮廓清晰可辨，而其他方法在强噪声下无法有效恢复原子结构。
- **关键优势**：得益于 HRTEM 专用噪声标定，模型在真实数据上的表现与合成数据一致，证明了噪声标定的有效性。

### 4.3 原子定位下游任务验证

- **任务**：在去噪后的图像上执行原子定位（检测每个原子的中心位置）。
- **验证目的**：去噪不仅仅是视觉上的提升，更重要的是服务于下游科学分析任务。
- **结果**：基于 SCGN 去噪结果的原子定位精度显著高于基于其他方法的定位精度，证明了去噪质量直接影响科学分析的可靠性。

## 五、消融实验

### 5.1 空间偏差引导加权的贡献

- 移除空间偏差引导加权（仅保留频率域处理）：PSNR 下降。
- 表明：空间域的差异化处理对于恢复局部原子特征至关重要。不同区域的信号强度差异需要自适应的卷积策略。

### 5.2 频率带引导加权的贡献

- 移除频率带引导加权（仅保留空间域处理）：PSNR 下降。
- 表明：频率域处理对于利用原子排列的周期性特征去噪具有不可替代的作用。

### 5.3 双域协同的效果

- 同时移除两个模块：性能大幅下降。
- 表明：空间域和频率域的处理是互补的，空间域恢复局部细节，频率域利用全局周期性，两者缺一不可。

### 5.4 HRTEM 噪声标定的贡献

- 使用未标定的随机噪声训练：真实数据性能下降。
- 使用 STEM 噪声标定训练：性能下降（因噪声类型不匹配）。
- 使用 HRTEM 专用噪声标定训练：性能最佳。
- 表明：针对特定成像模式的噪声标定对模型泛化能力至关重要。

## 六、深度分析

### 6.1 为什么需要空间 + 频率双重引导？

**空间域的局限**：在空间域中，信号和噪声是混合在一起的，尤其是在极低信噪比下，单个像素无法判断其是信号还是噪声。但不同区域的统计特征（如局部标准差）提供了区分信号与噪声的线索。

**频率域的局限**：频率域可以很好地分离周期性信号和随机噪声，但对于非周期性信号（如无序结构中的原子）的恢复能力有限。同时，频率域处理难以保持局部空间细节。

**双重引导的互补性**：
- 空间域通过局部统计特征自适应调整卷积操作 → 处理局部异质性。
- 频率域通过频带特征选择性增强/抑制 → 利用全局周期性先验。
- 两者结合，既保留了局部细节的灵活性，又利用了全局结构的先验知识。

### 6.2 为什么用统计特征（标准差）而非学习的特征？

这是一个关键设计选择。论文选择了显式计算的统计特征（空间域用标准差，频率域用 FFT）来引导去噪，而非让网络端到端学习这些特征。理由如下：

1. **可解释性**：统计特征具有明确的物理含义（标准差反映波动程度，频率反映周期性），便于理解网络的决策依据。
2. **先验知识的利用**：HRTEM 图像中信号和噪声的统计特性是已知的，直接使用这些先验比让网络从数据中重新发现更高效。
3. **对数据量的需求降低**：学习的特征需要大量数据来训练，而统计特征可以直接计算，减少了训练数据的需求。
4. **稳定性**：统计特征的计算是确定性的，不受训练过程随机性的影响。
5. **Yau-Yau 滤波器的启发**：传统信号处理中，基于统计特征的非线性滤波已经被证明在提取信号方面有效，将其迁移到深度学习框架中是合理的。

### 6.3 浅层网络的合理性

SCGN 使用的是相对浅层的网络（少量卷积层 + n 个增强块），而非深层的 U-Net 或 Transformer 架构。这种设计选择是合理的：
- HRTEM 图像的信号（原子位置）本质上是简单的点状结构，不需要过于复杂的特征提取。
- 过深的网络可能引入过拟合风险，尤其是训练数据相对有限时。
- 统计特征引导已经提供了足够的先验信息，降低了网络的深度需求。

## 七、Baseline 改善点

### 7.1 相对于传统去噪方法

| 方面 | 传统方法（高斯/维纳/双边滤波） | SCGN |
|------|------|------|
| 极低信噪比 | 几乎完全失效 | 有效去噪 |
| 原子结构保持 | 模糊化原子位置 | 清晰恢复 |
| 自适应能力 | 固定参数 | 统计特征引导 |

### 7.2 相对于现有深度学习方法

| 方面 | AtomSegNet/SFIN | SCGN |
|------|------|------|
| 无序结构去噪 | 效果有限 | 专门优化 |
| 噪声标定 | 通用/STEM专用 | HRTEM专用 |
| 差异化处理 | 统一处理 | 空间+频率双重引导 |
| 下游任务支持 | 未专门验证 | 原子定位验证通过 |

### 7.3 主要改善点

1. **引入了统计特征引导机制**：这是最核心的创新，使网络能够根据信号/噪声的统计特性进行自适应处理。
2. **HRTEM 专用噪声标定**：填补了 HRTEM 噪声标定的空白，确保了训练数据与真实数据的一致性。
3. **无序结构数据集**：首次提供包含无序原子排列的去噪数据集，支持成核过程研究。

## 八、不足与局限

### 8.1 通用性受限

- SCGN 是专门为 HRTEM 快速成像设计的，其统计特征引导策略基于原子图像的特殊性质（点状原子、周期性排列），可能难以直接迁移到自然图像去噪或其他类型的显微图像去噪。

### 8.2 网络架构相对简单

- 相比当前流行的 Transformer 或大型混合架构，SCGN 的网络设计较为简单（浅层卷积网络 + 统计特征引导）。虽然在 HRTEM 任务上有效，但对于更复杂的去噪场景可能不够强大。

### 8.3 仅支持灰度图像

- 输入输出均为单通道灰度图像（H x W x 1），不支持多通道或彩色图像处理。

### 8.4 数据集规模

- 虽然论文提出了新的数据集生成方法，但未明确报告数据集的规模（训练样本数量等），也未能与更多基线方法进行比较。

### 8.5 噪声模型的假设

- 噪声标定方法基于特定 HRTEM 设备和参数，对于不同设备或不同成像条件下的噪声泛化能力未做充分验证。

### 8.6 缺少与其他去噪范式的比较

- 未与最新的 Transformer-based 或扩散模型（Diffusion Model）等去噪方法进行对比，这些方法在其他领域已经展现了强大的去噪能力。

---

## 九、一句话总结

SCGN 通过在空间域（标准差引导）和频率域（频带特征引导）分别利用统计特征自适应引导去噪过程，并配套提出 HRTEM 专用噪声标定方法和无序结构数据集，有效解决了快速 HRTEM 成像中极低信噪比下的原子级去噪难题。

## 十、生活化例子：收音机调频类比

想象你正在用一台老旧的收音机听广播，但信号非常微弱，混杂着大量"滋滋"的噪声。SCGN 的工作方式就像一个智能的收音机调频系统：

**空间偏差引导加权 = 调节音量（不同位置信号强弱不同）**

- 收音机信号在不同房间的强度不同——客厅信号强（类似原子位置，标准差大），卧室信号弱（类似纯噪声区域，标准差小）。
- 智能系统根据每个房间的信号强度自动调节音量：信号强的地方调高音量（保留细节），信号弱的地方调低音量（抑制噪声），避免在信号弱的地方把噪声也放大。

**频率带引导加权 = 调节频道（信号和噪声在不同频段）**

- 广播信号在特定频段（低频），噪声分散在各个频段（高频为主）。
- 智能系统识别出哪些频段是有用的广播信号（低频，含原子周期性），哪些是噪声（高频），然后针对性地增强信号频段、抑制噪声频段。
- 就像收音机自动锁定信号最强的频道，同时过滤掉其他频道的干扰。

**双重引导的协同 = 同时调音量和调频道**

- 只调音量（空间域）：知道哪里信号强，但无法区分信号和噪声在同一位置的混合。
- 只调频道（频率域）：知道哪个频段有信号，但无法适应不同位置的信号强度变化。
- 两者结合：既能精准定位信号频段，又能根据不同位置自适应调节，最终清晰还原广播内容。

**HRTEM 噪声标定 = 了解这台收音机的特定噪声特征**

- 不同品牌的收音机有不同类型的噪声。HRTEM 的噪声和 STEM 的噪声不同，就像不同收音机的底噪特性不同。
- 先"标定"这台收音机的噪声特征（测量它在不同条件下的噪声模式），然后用这些信息生成训练数据，让智能系统"提前学习"这种特定噪声，从而在实际使用中更好地去除噪声。

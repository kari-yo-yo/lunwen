## 二、痛点分析

### 2.1 图像去雨任务的核心挑战

| 痛点编号 | 痛点描述 | 深层原因 | 现有方案的不足 |
|----------|----------|----------|----------------|
| **P1** | CNN感受野受限，难以捕获全局特征 | 卷积核尺寸固定，局部操作难以建模长距离依赖 | 传统CNN去雨方法在密集雨纹场景下效果不佳 |
| **P2** | Transformer忽略局部细节，冗余信息干扰 | 自注意力计算所有token相似度，混入不相关信息 | 纯Transformer方法在恢复精细纹理时表现不足 |
| **P3** | 缺乏有效的局部-全局特征融合机制 | 局部特征和全局特征分别提取后简单拼接或相加，未能实现真正的互补融合 | 双分支结构的去雨网络中，特征融合模块设计粗糙 |
| **P4** | 高频雨纹信息与低频背景信息纠缠 | 雨纹在频域表现为高频成分，与图像边缘等高频细节难以区分 | 现有方法未能有效分离高低频信息进行处理 |

### 2.2 具体场景痛点

| 场景 | 挑战 | MFFDNet之前的SOTA瓶颈 |
|------|------|------------------------|
| **轻度雨纹 (Rain200L)** | 雨纹稀疏但需要保留背景细节 | ECNet: 46.64dB, 但对真实场景泛化差 |
| **重度雨纹 (Rain200H)** | 雨纹密集且方向多变 | HINet/MPRNet在重度雨纹下易产生伪影 |
| **真实雨景 (Real-world)** | 无GT数据，合成到真实域差距大 | 监督学习方法在真实场景下性能显著下降 |

## 三、核心方法

### 3.1 总体架构

MFFDNet采用**三阶段顺序结构**：浅层特征提取网络 → 深层特征提取网络 → 去雨网络。

```
输入雨图 (3×H×W)
    │
    ▼
┌─────────────────────────────────┐
│     浅层特征提取 (3×3 Conv)      │
│        X0 ∈ R^(C×H×W)          │
└─────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────┐
│      深层特征提取 (N个阶段)       │
│  ┌───────────────────────────┐  │
│  │   阶段 i                   │  │
│  │  ┌─────┐  ┌─────┐  ┌────┐│  │
│  │  │CSAB │→ │ WTB │→ │MFFU││  │
│  │  │(局部)│  │(全局)│  │(融合)││  │
│  │  └─────┘  └─────┘  └────┘│  │
│  └───────────────────────────┘  │
└─────────────────────────────────┘
    │
    ▼
┌─────────────────────────────────┐
│       去雨网络 (SwinIR-based)    │
│       输出去雨图像               │
└─────────────────────────────────┘
```

### 3.2 通道-空间注意力块 (CSAB)

CSAB是MFFDNet的核心局部特征提取模块，包含两个子模块：

**1) 残差通道注意力 (Residual Channel Dominance)**
- **思想**: 将高频信息视为雨纹去除的关键元素
- **操作**: 通过旁路跳跃连接保留低频信息，主路专注于建模高频信息
- **效果**: 有效分离高低频成分，减少雨纹对背景细节的干扰

**2) 增强空间注意力 (Enhanced Spatial Attention)**
- **思想**: 直接建模图像中雨纹的空间分布
- **操作**: 空间注意力图指导网络关注雨纹区域
- **效果**: 提升对雨纹位置的感知能力

```
输入特征 X
    │
    ├──→ [残差通道注意力] ──→ 高频特征增强
    │
    └──→ [增强空间注意力] ──→ 空间位置感知
    │
    └──→ 融合输出
```

### 3.3 窗口Transformer块 (WTB)

WTB负责捕获全局特征：
- 将图像划分为不重叠窗口
- 在每个窗口内计算自注意力
- 通过移位窗口机制实现跨窗口信息交互
- 将3D图像特征转换为2D token形式处理

### 3.4 混合特征融合单元 (MFFU)

MFFU是MFFDNet最具创新性的设计，实现局部特征与全局特征的深度互补融合：

**融合策略**:
- **全局特征校准**: 使用局部特征细化全局特征，使其具备局部细节
- **局部特征增强**: 使用全局特征校准局部特征，使其具备全局上下文
- **互补融合**: 产生同时包含局部和全局信息的判别性特征表示

```
局部特征 X_L (来自CSAB)     全局特征 X_G (来自WTB)
        │                           │
        ▼                           ▼
   ┌─────────┐                ┌─────────┐
   │ 局部→全局 │                │ 全局→局部 │
   │ 校准     │                │ 增强     │
   └─────────┘                └─────────┘
        │                           │
        └───────────┬───────────────┘
                    ▼
              融合特征 X_F
```

## 五、总结与启发

### 5.1 核心贡献

1. **CNN-Transformer混合架构**: 巧妙结合CNN的局部特征提取能力和Transformer的全局建模能力
2. **CSAB模块**: 通过通道-空间双注意力机制有效分离高低频信息
3. **MFFU融合策略**: 实现局部与全局特征的深度互补融合，而非简单拼接

### 5.2 使用建议

| 场景 | 建议 |
|------|------|
| **轻度雨纹去除** | MFFDNet表现优异，可直接使用 |
| **重度雨纹/真实场景** | 建议结合半监督或域自适应方法提升泛化性 |
| **实时应用** | 模型参数量和计算量适中，适合部署 |
| **特征融合设计** | MFFU的互补融合思想可迁移到其他双分支网络中 |

### 5.3 与相关方法的对比

| 方法 | 架构 | 局部特征 | 全局特征 | 融合策略 |
|------|------|----------|----------|----------|
| MPRNet | 三阶段编解码 | 强 | 弱 | 阶段间渐进融合 |
| Restormer | 纯Transformer | 弱 | 强 | 无显式融合 |
| MFFDNet | CNN+Transformer双分支 | 强(CSAB) | 强(WTB) | 互补融合(MFFU) |
